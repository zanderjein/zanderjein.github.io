This page saves to the site, so it needs a key. You only do this once per device.

  1. Open GitHub, new fine-grained token.
  2. Repository access: Only select repositories, then zanderjein.github.io.
  3. Under Permissions, press Add permissions, tick Contents, then change its access from Read-only to Read and write. Nothing else.
  4. Press Generate token at the bottom, copy it, and paste it here.
